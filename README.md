# Radiant2 

Radiant2 homepage.

## Repository layout

Project setup follows standard Vite project.

Tech stack is: Vite, JavaScript, React, Tailwind, Shadcdn.

* Main app and pages are in `src`
* Static assets are in `public`

## Setup

* Run dev: `npm run dev`
* Run build: `npm run build`
* Run linting: `npm run lint`
